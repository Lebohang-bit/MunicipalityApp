## 1. Overview

The Municipal Services Application is a Windows Forms application developed for South African municipalities. It provides citizens with a simple, accessible platform to:

- Report municipal issues such as water outages, potholes, and faulty street lights.
- Browse upcoming local events and community announcements.
- Receive personalised event recommendations based on their interests.

The application is built on the .NET Framework 4.7.2 and uses a navy and white colour scheme designed for clarity and accessibility.


## 2. Features

### Part 1 Features

- Main menu with three options (Report Issues, Local Events, Service Status).
- Report Issues form with location, category, description, and file attachment.
- Progress bar with motivational messages to guide the user.
- In-memory storage of reported issues using generic lists.
- MessageBox feedback for success and error states.
- Navigation back to the main menu.

### Part 2 Features

- Local Events & Announcements form with a full event listing.
- Search by category using a dropdown filter.
- Search by date range using date pickers.
- Event details popup on row click.
- Personalised recommendation panel that learns from user interactions.
- Advanced data structures for efficient event management.
- Custom priority queue implementation for .NET Framework compatibility.
